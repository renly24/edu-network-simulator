# ネットワーク通信シミュレータ（教育用）

SNS に画像を投稿するときに、スマホと Web サーバの間でデータがどう流れるかを、TCP/IP の 4 つの層（アプリケーション層・トランスポート層・インターネット層・ネットワークインタフェース層）でステップごとに確認できる教育用の Web アプリです。

公開ページ: https://renly24.github.io/edu-network-simulator/

## 学べること

全5章・27枚のスライドで、問題を解きながら進めます。

1. **パケットにする**：送信側で画像を分割し、TCP・IP・イーサネットのヘッダを付けていく流れ（カプセル化）
2. **行き先を決める（IP）**：ルータが宛先 IP アドレスと経路表を見て次の行き先を決める様子、パケットごとに経路が変わることやパケットロス
3. **データを直す（TCP）**：シーケンス番号で欠けに気づき、確認応答（ACK）と再送、並べ替えで元のデータに戻す流れ
4. **UDPだったら？**：再送も並べ替えもしない UDP との違いと、それぞれが向いている通信
5. **返事とまとめ**：Web サーバからの返事と、5問のまとめテスト（採点・見直し付き）

### 問題の種類

- **予想問題**：アニメーションの前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません
- **体験問題**：ルータ役として次の行き先を選ぶ、足りないデータを見つける、並べ替える、TCP と UDP を仕分けるなど、自分で操作する問題
- **確認問題**：章の終わりと最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題のスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして GitHub Pages に公開します。
